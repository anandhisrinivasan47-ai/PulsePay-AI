## Brand & Style

This design system establishes an AI-native financial intelligence environment engineered for high-frequency operations, algorithmic capital allocation, and real-time treasury telemetry. The aesthetic synthesizes clinical technical precision with deep institutional authority.

Rather than relying on legacy enterprise corporate softness, the visual identity deploys an experimental structural framework: razor-calibrated metrics, asymmetric mathematical alignments, and sharp editorial density. Micro-surfaces project a sense of algorithmic cognition—instantaneous, surgical, and uncompromisingly modern.

The design movement anchors in **Analytical Modernism**: crisp planar surfaces, strict monoline separations, and high-velocity contrast ratios that ensure critical decision-making is frictionless and immediate.

## Colors

The palette is engineered around high-potency Indigo (`#4338CA`) acting as the structural core of authority and computation, elevated with Electric Cyan (`#06B6D4`) for live telemetry and speculative signals.

- **Primary (`#4338CA`):** Deployed for core transactional states, primary trigger commands, focused states, and foundational navigational anchors.
- **Secondary (`#06B6D4`):** Indicates dynamic stream updates, real-time AI inferences, and predictive trend overlays.
- **Tertiary (`#10B981`):** Institutional success metrics, positive liquidity deltas, and verified cryptographic states.
- **Neutral Core (`#0F172A` to `#F8FAFC`):** Deep slate typography set across surgical canvas surfaces. Neutral borders utilize calibrated slate dividers (`#E2E8F0`) to maintain tabular isolation without visual heaviness.
- **Alert Tones:** Calibrated amber (`#F59E0B`) for algorithmic warnings and risk flags; precision red (`#EF4444`) strictly reserved for system overrides, settlement failures, and capital drains.

## Typography

Typography balances technical vanguardism with raw functional clarity. 

- **Space Grotesk** commands display headers, dynamic valuation KPIs, and module titles. Its alternative geometric cuts emphasize computational forwardness.
- **Geist** handles the foundational data density: tables, analytics streams, micro-labels, and input fields. Its neutral, engineered proportions ensure maximum legibility at compact sizes.
- **Numerics:** All tabular data, currency metrics, and percentages must inherit tabular number formatting (`font-variant-numeric: tabular-nums`) to prevent horizontal jitter during live telemetry updates.

## Layout & Spacing

The structural layout utilizes a high-density, mathematical 12-column adaptive fluid grid engineered for real-time dashboards and dense command consoles.

- **Desktop (>= 1280px):** Persistent 280px computational sidebar alongside an elastic 12-column canvas with `1.5rem` gutters and `2.5rem` margins. Complex financial modules map to 3, 6, or 12 column aggregates.
- **Tablet (768px - 1279px):** Collapsed iconography sidebar (72px), grid downscaled to 8 columns with `1rem` gutters and `1.5rem` outer margins. Secondary visualizers collapse beneath primary ledgers.
- **Mobile (< 768px):** Single-column stack with bottom dock navigation. Margins contract to `1rem` to retain maximum viewport area for critical transaction flows.
- **Rhythm Rules:** Vertical rhythm follows strict 4px / 8px sub-grids. Metric groups use tight atomic spacing (`space-xs` and `space-sm`), while disparate card modules preserve `space-lg` separation to isolate analytical domains.

## Elevation & Depth

This system avoids heavy, blurred atmospheric shadows, relying instead on structural plane delineation and low-contrast surface tints:

- **Surface Levels:** 
  - Canvas Base: `#F8FAFC` (matte cool field).
  - Module Base: `#FFFFFF` (pure white actionable planes).
  - Nested Tiers: `#F1F5F9` (recessed inputs, metadata rows, and secondary trays).
- **Outlines over Shadows:** Elevation is created through hairline borders (`1px solid #E2E8F0`). Higher priority modules (such as active audit drawers or modal overlays) combine a crisp border with a tight, high-precision shadow: `0 4px 12px -2px rgba(15, 23, 42, 0.06), 0 2px 4px -1px rgba(15, 23, 42, 0.03)`.
- **Active Focus & AI Highlights:** AI insights and focused inputs emit a subtle indigo illumination: `box-shadow: 0 0 0 1px #4338CA, 0 1px 2px 0 rgba(67, 56, 202, 0.15)`.

## Shapes

The geometric architecture is defined by tight, deliberate restraint (`roundedness: 1`). Corners are lightly softened to avoid brutalism while resisting overly casual or pill-centric forms.

- **Micro Components (0.25rem / 4px):** Badges, tabular chips, inner segmented controls, and progress tracks.
- **Interactive Units (0.25rem / 4px to 0.5rem / 8px):** Buttons, text inputs, dropdown triggers, and filter selectors.
- **Macro Enclosures (0.5rem / 8px to 0.75rem / 12px):** Metric summary cards, analytical panels, charts, modal dialogues, and computational sidebars.

## Components

- **Buttons:**
  - *Primary:* Solid `#4338CA` with `#FFFFFF` text. Micro-radius (4px), 36px default height, typography set to `label-md`. Hover transitions to deep indigo `#3730A3` without dimensional movement.
  - *Secondary:* Pure white background, `1px solid #E2E8F0`, neutral slate text `#0F172A`. Hover triggers `#F8FAFC` background and `#CBD5E1` border tint.
  - *Ghost / Monoline:* Bare text with inline trailing icons for data navigation, transitioning to `#4338CA` text color on hover.

- **Data Tables & Lists:**
  - Built for high analytical density. Row height capped at 48px with sub-borders of `1px solid #F1F5F9`.
  - Header cells set to `label-sm` in uppercase slate `#64748B`, supporting inline sort vectors.
  - Hovering a row applies `#F8FAFC` background with tabular numerals snapping to primary focus.

- **Cards & Visual Containers:**
  - Flat `#FFFFFF` fill bounded by `1px solid #E2E8F0`. Top padding `space-lg`, bottom padding `space-lg`.
  - Section headers within cards utilize `headline-sm` with optional right-aligned micro-filters or timestamp indicators.

- **Chips & Status Badges:**
  - Compact geometry (height: 22px), `0.25rem` radius, uppercase tracking.
  - *Settled / Active:* `#ECFDF5` background with `#047857` text.
  - *Pending:* `#FFFBEB` background with `#B45309` text.
  - *Failed:* `#FEF2F2` background with `#B91C1C` text.
  - *AI Inference:* `#EEF2FF` background with `#4338CA` text paired with a static 4px indicator dot.

- **Form Inputs:**
  - Height: 40px, pure `#FFFFFF` fill, bordered by `1px solid #CBD5E1`.
  - Text rendered in `body-md` Geist. Focused state switches border to `#4338CA` with an immediate 1px inset ring. Placeholder text locked at `#94A3B8`.

- **Predictive AI Insights Banner:**
  - Structured card variant featuring a faint linear-gradient background from `#FFFFFF` to `#EEF2FF`, framed by a distinct cyan-to-indigo border accent. Incorporates real-time recommendation chips and instantaneous execution triggers.
