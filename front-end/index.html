Payment Workflow

  1. Create an invoice in INR.
  2. Backend converts the invoice amount into USD using the configured conversion factor.
  3. Backend creates a PayPal Sandbox order.
  4. Buyer approves the payment in PayPal Sandbox.
  5. PayPal redirects the buyer back to the frontend.
  6. Backend verifies the completed payment capture.
  7. Invoice status changes to paid only after verification.
